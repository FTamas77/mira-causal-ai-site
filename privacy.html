What is processed

This static site has no project-operated analytics or account registration. GitHub Pages may process visitor data under its privacy statement. When used, the experimental mira backend processes the data supplied to a scientific request; no user calculation history is stored in a mira project database. Limited technical logs may be retained by the hosting provider.

Why and where

Scientific request data is processed to return calculations. Operational information supports service reliability and security. GitHub hosts the site and public issues; Render hosts the research backend; ChatGPT, if used, processes conversations under OpenAI's separate terms and controls. Provider retention and processing locations may differ.

Retention

Scientific inputs are processed in memory; mira does not keep a calculation history. Render retains service logs according to the workspace plan: 7 days (Hobby), 14 days (Pro), or 30 days (Scale/Enterprise). GitHub and OpenAI handle their own records under their respective policies.

Requests and choices

Use only data you have permission to share. You may manage ChatGPT and GitHub content using those providers' controls. For privacy requests, open an issue asking for a private contact channel, without posting personal details. Applicable data-protection rights remain unaffected.
