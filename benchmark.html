Research / synthetic experiment

Causal discovery benchmark

Two new ChatGPT conversations received the same unseen, 900-row synthetic industrial cooling dataset. One used the lightweight mira connector; the other used ordinary built-in analysis.

ChatGPT alone identified interesting delayed correlations but could not execute specialized discovery in its test sandbox. The mira-enabled run reported formal causal-discovery results, scored afterward against the hidden synthetic generating structure. The comparison concerns this specific experimental workflow.

Experimental setup

Both runs used the same 900 × 6 numeric data, lags 0–2, α = 0.05 and no causal priors. Neither was supplied with structural equations or the generating graph.

Exploratory analysis

The baseline checked the complete file and calculated ordinary lagged Pearson correlations with Python, pandas and NumPy. The required scientific package was unavailable in that environment; installing it was outside the test protocol.

  • 900 valid observations; 899 exact 15-minute intervals
  • Strong lagged flow–temperature associations identified
  • No formal causal-discovery edge table or conditional-independence tests
  • Correctly declined to estimate do-effects or an optimal cooling flow

Formal causal discovery

The user-shared report records a completed formal time-series analysis using all 900 observations.

  • 16 lagged links + 2 same-time links reported
  • 15 planted lag-1 links recovered
  • 3 extra links (2 same-time, 1 lagged)
  • 260 reported CI-test calls, test statistics and input identifiers
  • Correctly declined unidentifiable intervention-effect claims
What mira added here: an available formal time-series causal discovery execution path and an inspectable temporal link graph, not simply arithmetic or a plausible explanation. The baseline demonstrated real exploratory value too. This experiment measures two specific tool configurations—not the inherent ability of ChatGPT to use scientific Python elsewhere.

Scope of the experiment

The benchmark intentionally withheld structural equations and intervention outcomes. Both conversations explicitly declined to compute do(flow = 110) vs do(flow = 100) or recommend an optimal flow.

What this test demonstrates

  • Execution of a specialized algorithm in the mira-enabled configuration
  • Exact recovery of all planted temporal links in this single synthetic sample
  • Quantified false positives and transparent statistical provenance
  • Independent, useful exploratory analysis without the plugin

What it does not establish

  • Production reliability or real-world causal validity
  • General accuracy on other datasets, seeds or settings
  • Causal effect identification or automatic SCM estimation
  • That other ChatGPT environments cannot run specialized scientific packages
  • That the public ChatGPT app has passed review

At α=0.05 no multiple-testing correction was applied. Two reported same-time links (p=0.01921 and 0.04006) and one lagged vibration→flow link (p=0.004863) do not match direct edges of the synthetic DGP. No backend internal CI-test history or full orientation trace was provided.

Conclusion

The measurable benefit in this experiment: mira made formal temporal causal analysis available in ChatGPT and produced a structured statistical graph. Against a withheld synthetic DGP, it recovered all 15 planted links, with 3 false positives. The ChatGPT-only configuration still performed meaningful lagged-correlation analysis, but had no installed specialized discovery implementation. Neither configuration identified intervention effects. This is a useful one-run research result, not a proof of general product superiority.

Pre-release, private mira v0.4.0, 19 November 2026. A multi-seed evaluation using the released public app should follow app approval.
